# Web Projects

This repository serves as a centralized monorepo for various web projects. These projects were originally developed in separate repositories but have been consolidated here to simplify management and keep everything in one place. The original Git histories for all projects have been preserved.

## Project Structure

### Independent Web Projects

* **event-booking-platform**: A dynamic event management web application featuring custom interactive UI layouts, guest reservation workflows, and integrated payment processing for private social gatherings.
* **fashion-night**: An elegant, highly visual landing page built for an exclusive fashion event, integrated with a secure ticket booking workflow and automated seat reservation.
* **thomas-zbienen**: A responsive portfolio showcase designed with advanced, semantic CSS for a professional real estate expert specializing in property valuation and structural analysis.

### Student and Campus Ecosystem

* **cesi-arena**: A real-time multiplayer dashboard and tournament bracket management platform designed to track competitive engineering school matches and live scores.
* **cesi-drop**: A secure, full-stack digital photo-sharing platform engineered for campus life, student associations, and engineering school events.
* **kompas**: An educational platform designed to assist engineering students throughout their academic journey at CESI, featuring interactive study tools such as flashcards, past exam papers, and revision tests.
* **portfolio-studio-cesi**: The official frontend showcase web application built to centralize, catalog, and display media assets generated by the engineering school's photography and creative club.

### Trading and Finance

* **tnptrading**: A scalable, production-ready backend API implemented in TypeScript to orchestrate trading logic, aggregate real-time market data, and handle secure user transactions.
